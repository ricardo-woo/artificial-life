# Security Policy

## Supported Versions

Artificial Life is currently under active development and does not maintain multiple supported versions.

Security fixes, when applicable, will be made against the latest version of the project.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest         | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability in Artificial Life, please report it privately rather than opening a public GitHub issue.

You can report vulnerabilities through the repository's **Security** tab using **Report a vulnerability**, if available.

Please include:

* A description of the vulnerability
* Steps to reproduce it
* Any relevant code or files
* The potential impact of the issue

Please allow some time for the issue to be reviewed. If the vulnerability is confirmed, it will be addressed in a future update.

For general bugs or issues that are not security-related, please open a regular GitHub issue instead.
